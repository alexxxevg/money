# Свои деньги

PWA для телефона и планшета: сборы коллег, мероприятия, передачи денег, личные долги и планирование следующего года.

## Развёртывание

Node.js 24, PostgreSQL 17. Coolify: публичный репозиторий, Build Pack Docker Compose, файл `/docker-compose.yaml`. Для HTTP-сервиса `money` указать `https://money.alexevgproject.ru:3000`. PostgreSQL работает только во внутренней сети, данные сохраняются в томе `money-db`. Пароль базы генерирует Coolify через `SERVICE_PASSWORD_MONEYDB`; не коммитить его в Git.

Локально: `npm ci`, настроить `DATABASE_URL` и `APP_URL=http://localhost:3000`, затем `npm start`.

Вход и регистрация по email/паролю. Пароли хешируются scrypt с отдельной солью, случайные токены сессий хранятся в базе в виде SHA-256. Cookie HttpOnly/SameSite, Secure на HTTPS, срок 30 дней. Данные и сессии привязаны к владельцу. Сброс пароля по почте в этой версии не реализован.

Синхронизация каждые 15 секунд и после изменений. Изменения без связи остаются в локальной копии аккаунта; для нового входа или открытия после перезапуска нужен интернет. Проверка версии предотвращает перезапись при одновременном редактировании: при конфликте скачать локальную копию и загрузить серверную в настройках. При выходе синхронизированная локальная копия очищается.

Импорт проверенной истории — через Настройки → Восстановить данные. В публичном репозитории нет реальных финансовых данных. Настроить резервное копирование PostgreSQL отдельно; JSON-копии можно скачать из приложения.

## Проверка

`npm test` — финансовая модель, пароли, токены, офлайн-очередь и конфликт версий.

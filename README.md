# Свои деньги

PWA для телефона и планшета: сборы на мероприятия, взносы коллег, передачи и расходы, личные долги и частичные возвраты.

## Возможности

- Справочник коллег и дней рождения.
- Создание разовых и повторяющихся сборов; отдельные планы взносов для участников.
- Частичные оплаты с датами, сбор по месяцам.
- «Сбор завершён» — необходимые деньги собраны. «Расчёты завершены» — остаток равен нулю, событие перемещается в архив.
- Создание дней рождения на выбранный год и перенос регулярных мероприятий на следующий год без оплат и дубликатов.
- Учёт «Я дал в долг», сроки, частичные возвраты и остатки.
- Установка на главный экран и работа без интернета после первого запуска.
- JSON-копии и проверка данных перед восстановлением.

## GitHub Pages

В репозитории: **Settings → Pages → Source → GitHub Actions**. Workflow `.github/workflows/pages.yml` проверяет расчёты и публикует содержимое `dist/` после push в `main`. Также можно запустить его вручную во вкладке Actions. URL приложения будет показан в результатах deployment.

Все ресурсы, manifest и service worker используют относительные пути, поэтому приложение работает и в подпапке `/svoi-dengi/`.

## Локальный запуск

```sh
python -m http.server 4173 --directory dist
```

Открыть `http://localhost:4173`. На телефоне установка PWA требует HTTPS-хостинга. Android: меню браузера → «Установить приложение». iPhone / iPad: Safari → «Поделиться» → «На экран Домой».

## Данные

Приложение начинает с пустой базы. Демонстрационный пример включается явно, использует вымышленные имена и суммы. Excel, реальные взносы, телефоны, токены и настройки Sites в репозиторий не включаются.

Записи хранятся в localStorage текущего браузера. Автоматической синхронизации между устройствами нет. Регулярно скачивайте резервную копию; очистка браузерных данных удалит записи.

При переходе на другой домен сохранённые записи автоматически не переносятся. Скачайте JSON-копию в старой версии приложения и восстановите её в новой через настройки.

Денежные суммы хранятся в целых копейках. Перевод авансом не создаёт личный долг автоматически. Счета брокера не включены.

## Проверка

```sh
npm test
```

Для работы и тестов дополнительные npm-пакеты не требуются. При выпуске обновления изменяйте значение `CACHE` в `dist/sw.js`.
